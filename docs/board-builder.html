Goal type cheat sheet

Item, source, NPC and pet names are case-insensitive and * matches anything — Ancient page* matches all four pages. Every goal has a count (how many times it must happen).

DropSpecific item drops, optionally only from certain monsters/chests ("5x Ancient pages from Mithril dragons"). Tick distinct for "X different items from this list".
Raid purpleUniques from the chosen raids' reward chests ("3x ToA purples").
Boss kill countKill count gained since the player imported the board, read from kill count chat messages ("100 Zulrah kills"). Bosses and activities only. Kills the player had before importing don't count.
NPC killsKills of any monster, no kill count message needed ("kill 500 Men"). A kill counts for whoever the game awards the loot to (most damage — ironman rules), so an NPC two teammates fight is never counted twice. Pick NPCs that drop something (even bones); the rare monsters with empty drop tables can't be counted.
PetAny pet, or specific pets (players need the collection log chat notification enabled for specific pets).
XPXP gained in a skill, counted from the moment the player imports the board.
Course lapsRooftop/agility course laps ("100 Canifis laps"), detected the same way RuneLite's lap counter works. Marks of grace work as a Drop goal with item "Mark of grace" and (optionally) the course name as source — but note they're tracked from the player's inventory, which is cheatable (e.g. dropping marks and relogging), so either run mark tiles on trust or require before/after inventory screenshots as proof.
Loot valueA single loot pile worth at least X gp at GE prices ("a 4m+ drop").
Chat messageA game message matching a regex — speed times, delve levels, quest completions. Example for sub-7 Corrupted Gauntlet: Corrupted challenge duration: [0-6]:[0-5][0-9]. The plugin turns the pattern into readable text for the progress bar; set a progress bar label if you want different wording.
ManualNot auto-trackable (POV recordings, community service). Players tick the tile off by hand.

A tile with several goals completes when all of them are done, or switch it to any for "X or Y" tiles.

Board ID & version: the ID ties progress to the board — keep it the same when fixing a live board and players keep everything (edit tiles in place; don't insert, remove or reorder them). Bump the version so players can see they have the latest. Changing the ID (or having none) makes edits reset progress.

Event window: set start/end times (entered in your timezone, stored as UTC) and the plugin only counts progress inside them — players can import the board early without pre-event drops, XP or kills leaking in.

Points: give tiles point values and the plugin shows the team's running total. Line pts pay per completed row/column/diagonal and blackout pts for finishing the whole board — both count toward the team total. For per-player contribution details, the team store's board view and portal list who contributed what to every goal.

Teams: players who connect with the same team code combine progress — counts add up across members ("2 uniques" can be one each from two people), "distinct" item lists count each different item once per team, and XP/kill counts sum. Give each team its own code and (optionally) its own Discord webhook for completion screenshots.
